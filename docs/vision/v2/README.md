# USMP v2.0 Vision (archived)

These documents are the original USMP v2.0 design. It focused on migrating OS-level applications
between Windows, macOS, Linux, Android and iOS, and proposed a service marketplace with a revenue
split.

They are kept as **future vision**, not as the current specification
([ADR 0001](../../adr/0001-open-protocol-first.md)). The current design is in the
[architecture overview](../../architecture/overview.md). OS-to-OS desktop app migration returns as
a domain family in Phase 6 of the [roadmap](../../plan/ROADMAP.md).

| Folder | Contents |
|---|---|
| [`protocol/`](protocol/) | Architecture, workflow, API sketch, security, business model, roadmap (v2) |
| [`schema/`](schema/) | Early schema sketches: application config, service registry, compatibility matrix |
